A clickable walkthrough of the app. Every screen is a real screenshot from the Expo web build. Tap the buttons on the phone, just like the real thing.

Try this path

  • Welcome → Create account
  • Discover → tap the ⓘ or the ♥
  • It’s a Match → Send a message
  • Pick an AI icebreaker, then hit send
  • Matches → tap the “people like you” banner

Tap anywhere else on the phone to see what’s tappable. Keyboard: ← → to step, Space to autoplay.

Also on desktop

On wide screens the web app switches to a sidebar with your conversations.
